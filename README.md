# -NETWORKWALKS-urielle-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
Cybersecurity Lab Setup
Overview
This lab focused on setting up the initial virtual cybersecurity lab environment using VirtualBox and Kali Linux.

The lab environment was configured with a dedicated NAT Network so that virtual machines can communicate with each other within the same private network.

Lab Tools:
VirtualBox
Kali Linux
7-Zip
VirtualBox NAT Network

Objectives:
Install the necessary virtualization and file management tools.
Create and configure a NAT Network in VirtualBox.
Set up Kali Linux as the first virtual machine.
Configure Kali Linux's network settings.
Set up the appropriate DNS configuration.
Check the assigned IP address and verify network connectivity.
Identify and resolve an initial internet connectivity issue.
Take a snapshot of the fully configured Kali Linux virtual machine.
